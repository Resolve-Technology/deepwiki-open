# Completeness Badge on the Wiki Page — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show the TSD/BRD completeness summary + "view full report" link persistently on the wiki page for the currently-displayed version, reusing the existing Jobs-panel component.

**Architecture:** A thin new `WikiCompletenessBadge` component fetches the current version's report from the existing `/api/wiki_completeness` endpoint and renders the existing `CompletenessSummary`. It is placed in the wiki header (under the "Generated by …" line). No backend, no new endpoint, no restyle.

**Tech Stack:** Next.js / React / TypeScript. Type-check + tests via vitest in a `node:20-slim` container (host has no node).

## Global Constraints

- Reuse `CompletenessSummary` and `completenessQuery` from `src/components/CompletenessSummary.tsx` unchanged.
- No backend / endpoint / dependency changes; the badge only calls the existing `GET /api/wiki_completeness?...&format=json|md` (via the Next proxy).
- The badge is best-effort: renders nothing when provider/model are empty, the fetch fails/404s, or the report is null (older wikis). It must never throw into the page.
- Component-file check commands run in a container: `docker run --rm -v "$PWD":/app -w /app node:20-slim sh -c "<cmd>"`.

- [ ] **Step 1: Create the component**

Create `src/components/WikiCompletenessBadge.tsx`:

```tsx
'use client';

import React, { useEffect, useState } from 'react';
import { CompletenessSummary, completenessQuery, CompletenessReport } from './CompletenessSummary';

// Fetches the completeness report for the currently-displayed wiki version and
// renders the shared CompletenessSummary. Renders nothing when provider/model
// are unknown, the fetch fails, or no report exists — never blocks the page.
export const WikiCompletenessBadge: React.FC<{
  repoInfo: { owner: string; repo: string; type: string };
  language: string;
  provider: string;
  model: string;
}> = ({ repoInfo, language, provider, model }) => {
  const [report, setReport] = useState<CompletenessReport | null>(null);

  const query = provider && model
    ? completenessQuery({ repo: repoInfo, language, provider, model })
    : '';

  useEffect(() => {
    setReport(null);   // clear any stale report immediately on any query change
    if (!query) return;
    let cancelled = false;
    (async () => {
      try {
        const res = await fetch(`/api/wiki_completeness?${query}&format=json`);
        const data = res.ok ? await res.json() : null;
        if (!cancelled) setReport(data as CompletenessReport | null);
      } catch {
        if (!cancelled) setReport(null);
      }
    })();
    return () => { cancelled = true; };
  }, [query]);

  if (!query) return null;
  return (
    <CompletenessSummary
      report={report}
      mdHref={`/api/wiki_completeness?${query}&format=md`}
    />
  );
};
```
